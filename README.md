# 🧠 Advanced SQL with SQLAlchemy, SQLite, and Pandas

This project demonstrates the use of **SQLAlchemy ORM**, **SQLite**, **Pandas**, and **Seaborn/Matplotlib** to:

- Create and interact with a relational database
- Run both **basic and advanced SQL queries**
- Visualize data insights with appealing charts

## 🚀 Features

- SQLite database created using SQLAlchemy
- ORM model with synthetic employee data
- Queries include:
  - Aggregations
  - Window functions (e.g., `RANK() OVER`)
  - Subqueries and joins
  - Advanced analytics queries
- Visualizations include:
  - Top salaries per department
  - Salary distribution
  - Department-wise averages
  - Outlier detection

## 📊 Libraries Used

- `SQLAlchemy` – ORM and raw SQL execution
- `SQLite` – Lightweight database engine
- `Pandas` – Data handling
- `Seaborn` & `Matplotlib` – Data visualization
